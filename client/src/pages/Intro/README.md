# Intro Page

This folder contains the complete editable intro page:

- `IntroPage.jsx` — React host and iframe integration.
- `IntroPage.css` — responsive host sizing.
- `page.config.js` — intro title and accessible page label.
- `IntroDocument.html` — page markup, burgundy theme styles, copy and its local JavaScript.

Edit `IntroDocument.html` to change the introduction page's wording, layout, and visual design. The burgundy logo and its matching dashboard brand line are shared with the workspace.
